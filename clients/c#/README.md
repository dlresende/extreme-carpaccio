# Extreme Carpaccio - C# Client

Minimal C# starter using ASP.NET Core minimal APIs.

## Prerequisites
- [.NET SDK](https://dotnet.microsoft.com/download) (>= 9.0)

## Install & Run
```bash
dotnet run
```

## Endpoints
- `POST /ping`: Responds with `pong`

```bash
curl -X POST http://localhost:3000/ping
```

## Tests
```bash
dotnet test extreme-carpaccio-client-csharp.sln
```
