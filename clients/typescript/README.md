# Extreme Carpaccio - TypeScript Client

Minimalistic TypeScript starter client for Extreme Carpaccio.

## Prerequisites
- [Node.js](https://nodejs.org/)

## Install & Run
```bash
npm install
npm start
```

## Endpoints
- `POST /ping`: Responds with `pong`

```bash
curl -X POST http://localhost:3000/ping
```

## Tests
```bash
npm test
```
