# Extreme Carpaccio - Java Spring Boot Client

Minimal Java starter using Spring Boot.

## Prerequisites
- JDK 17+
- Maven

## Install & Run
```bash
mvn spring-boot:run
```

## Endpoints
- `POST /ping`: Responds with `pong`

```bash
curl -X POST http://localhost:3000/ping
```

## Tests
```bash
mvn test
```
